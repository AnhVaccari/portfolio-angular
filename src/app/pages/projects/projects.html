Incident Tracker

🔗

Full-Stack • Spring Boot + Angular 21

Interface de gestion des incidents

Modal de création avec validation

Gestionnaire d'incidents IT pensé pour démontrer des décisions d'ingénierie, pas un simple CRUD : le workflow est une règle métier validée côté serveur (transition illégale → 409, même en contournant l'interface), et une couche IA résiliente assiste le triage sans jamais bloquer l'application.

Décisions techniques :
  • • Machine à états validée côté serveur (409 sur transition illégale, même via curl)
  • • Résistance à la concurrence : verrou optimiste (@Version)
  • • Triage IA (priorité/catégorie) en mode dégradé : timeout 3 s + repli local
  • • Détection de doublons sémantique (embeddings Ollama, similarité cosinus)
  • • PostgreSQL + Docker Compose (démarrage en une commande) · 72 tests
