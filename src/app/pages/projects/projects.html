Incident Tracker

🔗

Full-Stack • Spring Boot + Angular 21

Interface de gestion des incidents

Modal de création avec validation

Outil de suivi d'incidents IT qui va plus loin qu'une appli de gestion classique. Le cycle de vie d'un incident (Ouvert → En cours → Résolu → Fermé) est une vraie règle appliquée par le serveur : impossible de sauter une étape, même en essayant de contourner l'interface. Une IA propose la priorité et la catégorie — et si elle est indisponible, l'appli continue de tourner normalement.

Points clés :
  • • Le workflow est appliqué côté serveur : impossible de sauter une étape, même en contournant l'appli (réponse « 409 = interdit »)
  • • Deux personnes ne peuvent pas s'écraser en modifiant le même incident au même moment
  • • L'IA suggère priorité et catégorie ; si elle tarde ou plante, une méthode locale prend le relais — jamais de blocage
  • • Doublons détectés par le sens : « boîte mail cassée » et « impossible d'envoyer des mails » sont rapprochés, même sans mots communs
  • • Base de données PostgreSQL, démarrage en une seule commande (Docker), 72 tests automatisés

E-Commerce Platform

🔗 GitHub

Full-Stack • Spring Boot + Angular 21

Plateforme e-commerce complète : boutique publique, panier, commandes et back-office d'administration. L'accent est mis sur la sécurité (authentification JWT, accès par rôles) et l'intégrité des données (validation du stock à la commande).

Points clés :
  • • Sécurité : authentification JWT + accès par rôles (User/Admin) via Spring Security
  • • Intégrité des données : validation du stock au passage de commande
  • • Back-office admin complet (CRUD produits, utilisateurs, commandes)
  • • Boutique publique : catalogue responsive, recherche/filtres, panier persistant
  • • Architecture full-stack : API REST Spring Boot ↔ front Angular
